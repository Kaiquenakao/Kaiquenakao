## MLOps

| Component | Description |
|---|---|
| **Model Registry** | Versioning, metadata management, artifact storage, rollback and compliance tracking |
| **Feature Store** | Centralized feature management, reuse across models, training/production consistency |
| **Batch Inference** | Scheduled prediction pipelines at scale with result storage and output monitoring |
| **Kafka** | Real-time event streaming for feature pipelines and online inference triggers |
| **Experiment Tracking** | Hyperparameter logging, metric comparison, reproducible training runs with MLflow |
| **CI/CD for ML** | Automated retraining pipelines, model validation gates and deployment automation |
| **Monitoring** | Data drift detection, model performance degradation tracking, alerting in production |

## LLMOps

| Component | Description |
|---|---|
| **Fine-Tuning** | Domain-specific model adaptation with custom datasets and PEFT/LoRA techniques |
| **RAG** | Retrieval-Augmented Generation pipelines with vector databases (Pinecone, FAISS) |
| **RAGAS** | Automated RAG evaluation using faithfulness, answer relevancy and context precision |
| **Golden Dataset** | Curated ground-truth QA sets for benchmarking and regression testing of LLM outputs |
| **Prompt Catalog** | Versioned prompt library with metadata, ownership and performance annotations |
| **Prompt Engineering** | Systematic prompt design: zero-shot, few-shot, chain-of-thought, self-consistency |
| **Agent Orchestration** | Multi-agent systems with tool use, memory and structured reasoning loops |
| **LLM Observability** | End-to-end tracing, logging and cost tracking for LLM calls in production |
